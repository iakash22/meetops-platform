# Dev compose secrets (LOCAL DEV ONLY)

Generated by `scripts/gen-dev-secrets.sh`; every `*.txt` here is gitignored.
Compose mounts them read-only at `/run/secrets/<name>`:

| File                               | Used by                                                                  |
| ---------------------------------- | ------------------------------------------------------------------------ |
| `postgres_password.txt`            | postgres (`POSTGRES_PASSWORD_FILE`)                                      |
| `meetops_app_db_password.txt`      | initdb roles script, api/worker `DATABASE_URL`                           |
| `meetops_migrator_db_password.txt` | initdb roles script, migrate `MIGRATION_DATABASE_URL`                    |
| `redis_password.txt`               | redis healthcheck, app `REDIS_URL`                                       |
| `redis_acl.txt`                    | redis `--aclfile` (derived from redis_password, SHA-256 hashed)          |
| `minio_root_password.txt`          | MinIO (`MINIO_ROOT_PASSWORD_FILE`), minio-init only                      |
| `minio_app_password.txt`           | minio-init (creates scoped user), api/worker `STORAGE_SECRET_ACCESS_KEY` |

Apps get their URLs from `infra/compose/bin/with-secrets.sh`, which builds
`DATABASE_URL` / `MIGRATION_DATABASE_URL` / `REDIS_URL` / `STORAGE_SECRET_ACCESS_KEY`
from these files at container start, so passwords never pass through compose
interpolation or `docker inspect` env. Host-run dev (`pnpm dev`) still reads `.env`.
