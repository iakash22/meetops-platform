## Other hardening in M6

- Android `blockedPermissions` strips `READ/WRITE_EXTERNAL_STORAGE` and `SYSTEM_ALERT_WINDOW` (Expo defaults MeetOps doesn't use).
- `expo-dev-client` added so the `development` EAS profile (`developmentClient: true`) builds.
- Recording ids are allowlisted (`[A-Za-z0-9_-]`) before they touch a file path.
- No auto-start, background trigger or hidden capture path: capture begins only in the notice confirmation handler.
