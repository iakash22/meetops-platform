# Execution rules

Standing rule, effective 2026-10-21, in force until Akash explicitly authorizes Cursor.

## No-Cursor rule

1. Do not use Cursor Cloud Agents, Cursor Agent, or any other Cursor coding service for development.
2. Use only the Grok Bot box, its tools (shell, git, `gh`, approved connectors), and this repository.
3. If a task needs Cursor, stop and report to the Coordinator. Do not proceed.
4. Before delegating any work, state which execution service will run it and how it will be used.
5. If you cannot modify files or run commands, say so plainly. Do not fall back to Cursor.
